Services

Where the helper containers are. The defaults are the service names in the suggested docker compose file.

Recognition methods run in this order. When one can't identify a book, the next one takes over. Changes apply to each book from its next step.

1. Title announcement

Listens to the opening of part 1 for “[Someone presents:] The Title, by Author[, read by Narrator]”. Title and author are the minimum; the “presents” part and the narrator are optional. Then looks the title up in book catalogs.

Catalogs: {{range .AnnounceCatalogs}}{{end}}
2. Text search

Transcribes a random stretch from the middle of the set and searches catalogs that index the text inside books. If two or more books come back, it listens to another random stretch and searches with all the words heard so far.

Catalogs: {{range .TextCatalogs}}{{end}}
Path rules

Regular expressions tried in order against each set's folder path inside its library (for library /audiobooks, the set /audiobooks/a/b/c/d is matched as a/b/c/d); the first that matches decides the author, title and series shown for the book. Use named groups (?P<author>…), (?P<title>…) (required), (?P<series>…), (?P<index>…), (?P<narrator>…), (?P<year>…). Paths use /. Clear a pattern to delete its rule; change the order numbers to reorder.

Catalog limits

Requests allowed per period, comma-separated, e.g. 1/2s,300/1h. Searches wait in the queue until a slot is free. Units: s, m, h.
